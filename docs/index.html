How the games are processed

Run the pipeline ↗
01 · Extract

Download games

Download a fixed number of games from the archive, recording the source, checksum and time.

02 · Bronze

Remove duplicates

Keep each game ID once. Store raw files or Bronze tables privately and track their source.

03 · Silver

Validate games

Check ratings, dates, results and time controls. Keep invalid records separate.

04 · Gold

Group results

Calculate counts and outcomes by opening, rating and other game details. Publish only grouped results.
