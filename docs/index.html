Run the pipeline ↗
01 · Extract

Bounded PGN

Stream a Zstandard archive up to a fixed record limit. Record the source, checksum and retrieval time.

02 · Bronze

Keep the source

Deduplicate by stable game ID and retain raw records locally with batch lineage.

03 · Silver

Validate & type

Check analytics fields, timestamps, ratings and time controls; quarantine invalid records.

04 · Gold

Group & export

Aggregate openings, rating buckets and speed. Publish only group labels and counts.
